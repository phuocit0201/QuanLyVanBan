# Cursor Rules

This file lists all rules that Cursor should follow when working with this project.

## Rule Files

- [.cursor/rules/laravel-clean-architecture.mdc](laravel-clean-architecture.mdc) - Clean Architecture guidelines
- [.cursor/rules/php-code-standards.mdc](php-code-standards.mdc) - PHP coding standards
- [.cursor/rules/security.md](security.md) - Security best practices
- [.cursor/rules/performance.mdc](performance.mdc) - Performance optimization
- [.cursor/rules/i18n.mdc](i18n.mdc) - Internationalization (i18n) best practices

## Summary

These rules define the coding standards and best practices for this Laravel application:

1. **Clean Architecture**: Domain-Driven Design structure with clear separation of concerns
2. **PHP Standards**: PSR-12 compliance, PHP 8.x features, type safety
3. **Security**: JWT authentication, input validation, SQL injection prevention
4. **Performance**: N+1 queries prevention, caching, pagination, database indexing
5. **i18n**: Multi-language support (Vietnamese default, English)
